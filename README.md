# 信息论基础（第2版）· 第二章双数题精解

Cover & Thomas《Elements of Information Theory 2nd Edition》Chapter 2（熵、相对熵与互信息）双数题 2.2 – 2.48，共 **24 题**。

- 中文题目 + 手写风格中文解答
- 解答过程参考官方 Solutions Manual，逐步推导并注明所用定理
- 公式由 KaTeX 渲染，支持打印 / 导出 PDF

## 本地访问

直接双击打开 `index.html` 即可（公式库经 CDN 加载，需联网）。

## 部署到 GitHub Pages

1. 把本目录所有文件（含 `.github` 隐藏目录）上传到仓库根目录
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**
3. 等待 Actions 运行完成后，访问 `https://<用户名>.github.io/<仓库名>/`

## 文件结构

- `index.html` — 网站页面与渲染逻辑
- `problems.js` — 24 题的中文题目与解答数据
- `.github/workflows/deploy-pages.yml` — GitHub Pages 自动部署工作流

仅供学习参考。
